## Acceptance Matrix

| # | Requirement | Threat / Failure Mode | Independent Expected Result | Test Method | Evidence Required |
| :- | :--- | :--- | :--- | :--- | :--- |
| **REQ-1** | **Strict Recursive JSON Type Equality** | Outer-dict equality allows nested `1 == true`, `4.0 == 4`, `21.0 == 21` (Python truthy & numeric equality bypass). | Verifier rejects nested type substitutions: booleans $\neq$ integers, integers $\neq$ floats. Substituted types return `passed: false`. | Regression test with counterexample `{"valid": 1, "words": 4.0, "length": 21.0, "preview": "hello worl"}` vs expected `{"valid": true, ...}`. | Regression test failure log on unfixed code; passing log on fixed code. |
| **REQ-2** | **Exact JSON Schema Structure & Key Ordering** | Extra unexpected keys or missing required keys pass unnoticed; reordered arrays pass when order matters. | Verifier requires exact keys (`set(actual.keys()) == set(expected.keys())`); arrays must match element-by-element in order; duplicate keys and nonfinite numbers rejected. | Adversarial mutation suite: extra keys, missing keys, swapped array elements, null vs missing, NaN/Inf injection. | Unit test execution output in `tests/test_protected_verification.py`. |
| **REQ-3** | **Bounded JSON Input & Resource Envelope** | Deeply nested objects or massive strings cause DoS or stack overflow in verifier parsing. | Payloads exceeding 32 KB, nesting depth > 16, or non-string/non-dict root values are rejected fail-closed without crashing verifier. | Boundary fuzzing tests with nested structures and oversized payloads. | Test assertion logs and exception handling verifications. |
| **REQ-4** | **Systemic Authority & Native Execution Binding** | Unrelated native executions or forged origin labels borrow approval authority; historical pass reused after input change. | Controller verifies that task, lease, attempt, worker, model-response SHA-256, and contract SHA-256 strictly match. Historical passes are marked stale if bindings change. | Positive and negative tests through `CodeProposalReview.review` and `ProtectedVerification.current_result`. | Test execution records showing stale/cross-run rejections. |
| **REQ-5** | **Consume-Before-Execute Nonce Replay Lock** | Replayed verification grants or retransmitted network packets execute twice or forge passes. | Verification grant nonce is written to root audit store before execution starts; any repeated execution attempt raises `FileExistsError` and halts fail-closed. | Dedicated nonce replay test attempting duplicate execution of previously consumed grant. | Cryptographic receipt and root harness stderr capturing replay denial. |
| **REQ-6** | **Sandbox Isolation & Containment** | Generated candidate escapes container, writes to host, accesses network, or exhausts cgroup resources. | Systemd sandbox enforces `PrivateNetwork=yes`, `IPAddressDeny=any`, `RootImageOptions=ro`, `DynamicUser=yes`, and kills timeout/overflow processes cleanly. | Boundary probe suite exercising socket connect, filesystem writes, infinite loops, and stdout flood. | Systemd manager observations and cgroup `populated 0` confirmation. |
| **REQ-7** | **Test Adequacy & Mutation Resistance** | Test suite is superficial, allowing broken or hardcoded implementations to pass. | Approved test suites must reject defective implementations: constant/hardcoded answers, broken empty/malformed handling, incorrect whitespace/unicode. | Mutation testing against deliberate defective mutants; kill rate must exceed 90%. | Mutation test report mapping each mutant to the rejecting test case. |
| **REQ-8** | **Preserved Audit History & Rollback Safety** | Dropping audit tables destroys verification history; database migrations block concurrent production queries. | Database migration adds `software_review_items` without write locks or query timeouts; rollback retains historical audit trails; backup restoration verified. | Concurrent read/write concurrency test with automated backup/restore verification on disposable database. | Benchmark metrics: throughput, error count (0), lock duration (<10ms), restoration hash verification. |
| **REQ-9** | **Live Leased-Model Canary Revalidation** | Controller $\rightarrow$ Task $\rightarrow$ Lease $\rightarrow$ Worker $\rightarrow$ Model $\rightarrow$ Sandbox pipeline fails in live multi-node environment. | Authentic model generation (`qwen2.5:1.5b`) undergoes initial failure on edge cases $\rightarrow$ bounded revision without oracle leakage $\rightarrow$ full pass under fresh grant. | Live execution across Tailscale mesh to `qwen-laptop` and Linux rootfs container. | Cryptographic Canary evidence JSON with service PID stability checks. |
